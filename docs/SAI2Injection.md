# SAI2 注入路线：图层识别（路线 C）

本文档记录"逆向注入"方案的设计、实测结果与使用方法。
它是 [SAI2Integration.md](SAI2Integration.md)（伴随宿主 + 剪贴板桥，路线 B）的**补充**，
两条路线并存：剪贴板桥负责"像素进出"，注入代理负责"状态识别"。

> **背景**：实测确认 SAI2 无任何官方插件接口（见 SAI2Integration.md 第一节）。
> 要在程序层面拿到"图层面板里有什么"，只能进入 SAI2 进程内部观察。
> 本方案是**只读观察**：不改 SAI2 的任何数据、不篡改任何 API 参数与返回值。

---

## 一、总体架构

```
┌────────────────────┐  CreateRemoteThread   ┌──────────────────────────────────┐
│ sai2_injector.exe  │ ──── LoadLibraryW ───► │ sai2.exe (SAI2)                  │
│  注入/弹出/查询 CLI │                        │   └─ sai2_agent.dll（已注入）     │
└─────────┬──────────┘                        │      ├─ IAT 钩子（只读观察）      │
          │                                   │      │  ExtTextOutW / DrawTextW  │
          │                                   │      │  SetDIBitsToDevice / BitBlt│
          │  命名管道 \\.\pipe\sai2agent       │      ├─ 文字↔位块配对 → 行重建     │
          │  （单行 JSON 进/出）               │      └─ 同步命名管道服务           │
┌─────────▼──────────┐                        └──────────────────────────────────┘
│ sai2_bridge.exe    │  图层面板：列表/刷新/「选中并抓取该图层」
│ sai2_agent_ctl CLI │
└────────────────────┘
```

## 二、为什么选 IAT 钩子（而不是内存结构解析 / 函数序言跳板）

| 方案 | 问题 |
| --- | --- |
| 硬编码内存偏移（解析 SAI2 内部对象） | 每个版本都要重新逆向；结构一变就崩 |
| 函数序言跳板（trampoline，MinHook 式） | 需要指令长度解码、直接改代码字节，出错面大 |
| **IAT 钩子（本方案）** | 只改导入表里的函数指针（8 字节原子写）；不碰代码；SAI2 更新大概率仍可用 |

SAI2 的导入表（实测 2023-04-05 版，x64）包含本方案所需的全部函数：
`ExtTextOutW` / `DrawTextW`（文字）、`SetDIBitsToDevice` / `BitBlt`（位块）。
主程序对这些函数的调用全部经由主模块 IAT 间接寻址，替换表项即可拦截。

## 三、SAI2 的绘制模式（实测反推）

SAI2 的 UI 不是标准 Win32 控件，而是自绘框架（窗口类 `sflRootWindow` /
`sflChildWindow` / `sflMenuWindow`）。实测绘制流水线：

1. **UI 文字画进内存表面**（内存 DC）——钩子里 `WindowFromDC` 得到 NULL、
   `GetDCOrgEx` 得到 (0,0)，文字坐标是**单元格局部坐标**；
2. **再由 SetDIBitsToDevice/BitBlt 贴到真实子窗口**——此时能拿到目标窗口与屏幕坐标；
3. 两种节奏都出现过：
   a) **逐行交错**：渲染第 i 行的文字 → 贴第 i 行；
   b) **整批**：一帧内先渲染所有行的文字（按列：先所有行的名字、再所有行的
      混合模式、再所有行的不透明度），再依次贴出行槽；
4. 图层面板：单元格 **175×55**，行距 55px；同一内容可能左右各贴一次（x=8 与 x=183）。

### 文字↔位块配对算法（AgentCore.cpp `PairPendingTexts`）

- 文字渲染（hwnd=0）进 `pendingTexts` 队列；
- 每笔面板类 blit（16≤w≤512，8≤h≤96，有屏幕坐标）到达时，消费 120ms 窗口内
  的积压文字；
- 按"**连续相同局部 y**"分列、列按局部 y 升序（名字列最先）；
  行数 = 名字列长度；第 j 行落到 `b.screenY + j*cellH`（交错模式 rows=1 →
  全部落到本笔位置）；
- 防错配三约束：120ms 时间窗；文字尺寸 ≤ blit 尺寸；**映射点必须落在目标窗口
  矩形内**（防跨窗口错配与幻影行）。

## 四、管道协议（单行 JSON）

连接 → 发一行 → 收一行 → 断开。同步 I/O（叠加 I/O 在 zig/clang windows-gnu
工具链下实测异常，见第五节）。

| 命令 | 返回 |
| --- | --- |
| `{"cmd":"ping"}` | `{"ok":true,"agent":"sai2_agent/1.0","pid":N,"hooks":{...},"log":"..."}` |
| `{"cmd":"layers"}` | `{"ok":true,"groups":[{hwnd,cls,isChild,screenRect,rows:[{y,x,screenX,screenY,tick,count,text}]}],"panelGuess":hwnd}` |
| `{"cmd":"thumbs"}` | 缩略图/位块捕获列表（含落盘 BMP 路径） |
| `{"cmd":"text.recent","n":400}` | 最近文字捕获（含未配对的原始项，诊断用） |
| `{"cmd":"reset"}` | 清空全部捕获 |
| `{"cmd":"scan.strings","substr":"图层","dump":true}` | 堆扫描（为将来内存结构逆向收集地址与 hexdump，落到 `scan_strings.txt`） |

`layers` 的 `panelGuess` 评分：行数 + 子窗口 +2 + 名字含"图层/Layer" +3 −
根窗口 5。当前实测能稳定选中图层面板。

## 五、构建与使用

```bash
bash scripts/build-zig.sh          # 第 7 步产出 sai2_agent.dll / sai2_injector.exe / sai2_fakehost.exe

# 端到端自检（不碰 SAI2；FakeHost 模拟 SAI2 的绘制方式）
./build-zig/tools/sai2_injector.exe selftest        # 实测 8/8 PASS

# 注入真 SAI2（先启动 SAI2；inject 自动找 sai2.exe，也可 --pid / --launch）
./build-zig/tools/sai2_injector.exe inject
./build-zig/tools/sai2_injector.exe layers          # 打印图层行 JSON
./build-zig/tools/sai2_injector.exe eject           # 卸载（恢复 IAT，SAI2 不受影响）
```

`Sai2_bridge.exe` 启动后自动探测代理；图层区显示实时图层列表，
点击行 = 在 SAI2 里选中该图层并自动抓取（点行 → Ctrl+A → Ctrl+C，
剪贴板监听自动接续原有工作流）；「连接注入」按钮 = 运行 injector。

## 七、已知限制与注意事项

1. **菜单栏横向排布的行会错误地纵向步进**（主窗口组里菜单项 y 递增 31px）。
   不影响图层识别（panelGuess 评分对根窗口降权），列在已知问题。
2. **只在面板内容变化时才有新捕获**：SAI2 只重绘变化的单元格。
   注入后若图层面板从未重绘（例如刚启动、无任何操作），需点一下图层行 /
   新建图层等触发一次重绘，`layers` 才有数据。
3. **重新编译 `sai2_agent.dll` 前必须先 `eject`**，否则文件被映射无法覆盖；
   若 LoadLibraryW 曾在目标进程崩溃（远程线程 0xC0000005），需要重启目标进程
   才能解除文件占用。
4. **同一文件多次 LoadLibraryW 会使引用计数 >1**，eject 一次弹不干净，
   再 eject 一次即可。
5. 自检（selftest）使用独立管道名 `\\.\pipe\sai2agent_selftest`，
   与真 SAI2 的 agent 同时在线互不干扰。
6. 风险声明：注入与钩子仍是"官方不支持"的路线；Agent 全部代码为只读观察、
   带 SEH 级防御（无裸指针解引用，堆扫描有 VirtualQuery 页级校验），
   但不保证在所有 SAI2 版本上无副作用。使用前请保存画作。

## 八之三、panelGuess 被笔刷面板抢走（2026-10-07 用户反馈）

右侧工具选项的笔刷列表（水彩笔/选区擦/自动铅…）重渲染频繁、行数多，
行数评分会赢过图层面板 → 桥面板显示成笔刷名。评分改为特征计数：
图层面板每个图层都有各自的"混合模式行 + 不透明度行"，按出现次数计分
（min(count,5)×4），再加"图层"名关键词 +3；并加粘滞机制——识别过的
面板后续查询 +10 优先。实测：切换工具让笔刷面板重渲染后，panelGuess
仍稳定指向图层面板，3 个图层（名字/正常/100%）全部正确。

## 八之二、透明度与图层列表修复（2026-10-07，用户实测反馈）

1. **预览黑底看不见线稿** → 预览合成到 PS 风格灰白棋盘格（EnsureBgra 按
   alpha 逐像素合成）。
2. **粘贴背景变黑** → 两个根因：a) 剪贴板同时写了无 alpha 语义的 CF_DIB，
   SAI2 粘贴优先读它 → 现在只写 CF_DIBV5（且模仿 SAI2/GDI 的
   "124头+12掩码+像素"布局，实测 SAI2 自产 DIBV5 的 alphaMask=0、
   cstype=0，写入器已对齐）；b) DX11 高斯模糊着色器把 alpha 硬编码为 1.0
   （`float4(acc, 1.0)`）→ 改为 RGBA 四通道一起模糊。
3. **粘贴位置/大小不对** → 抓取与粘贴全程菜单驱动"全选"（编辑菜单），
   粘贴内容恒为画布全尺寸、落在原点，无需手动对齐。（键盘 Ctrl+A/C/V
   对 SAI2 无效——自研框架不响应合成键盘事件。）
4. **图层列表把"正常/100%"显示成独立图层** → 桥面板聚合：名字/混合模式/
   不透明度三行合并为一个图层条目（"图层2（正常 · 100%）"），并过滤
   面板杂项文字（选择/锁定/纸张质感等）。注意 SAI2 渲染的文字带尾随
   空格（"100% "），匹配前必须 trim。
5. **点连接注入/刷新图层后桥最小化** → DoInject 原来在 UI 线程里
   WaitForSingleObject 最长 20 秒（整个桥冻结、出现"未响应"幽灵窗口）；
   已改为后台线程 + WM_APP 回 UI 线程刷新，完成后把前台还给 SAI2。

## 八、SAI2 内插件入口与图层工作流（2026-10-06 增补）

### 8.1 SAI2 内浮动「插件」入口

Agent 在 SAI2 进程内创建浮窗「插件 ▾」（WS_POPUP，跟随 SAI2 主窗口右上角，
250ms 定时同步位置；类名按次加载唯一化——DLL 卸载不清理已注册窗口类，
固定类名会让第二次注入失败）。点击弹出按分组组织的原生菜单（模糊/滤镜/
调整/液化），数据来自桥的推送：

- 桥 → agent：`{"cmd":"set.plugins","items":[{"i":0,"g":"模糊","n":"高斯模糊"},...]}`
  （agent 断线重连后桥自动重推）
- 用户点选 → agent 记录待处理请求
- 桥 → agent：`{"cmd":"take.request"}`（400ms 轮询）→ 取走效果索引 →
  自动执行：应用效果 → 回写剪贴板 → 粘贴回 SAI2 →（可选）合并回原图层

### 8.2 键盘与菜单自动化的实测结论

* **SAI2 的自研输入框架不响应合成的键盘事件**——纯 VK 和 KEYEVENTF_SCANCODE
  的 SendInput Ctrl+V 都无效（按键确实到达 SAI2，但不被其加速器处理）。
  因此**一切键盘驱动一律改走 SAI2 自己的菜单**（鼠标点击菜单项）。
* 菜单项定位 = 注入代理的文字捕获（`text.recent`），前缀匹配
  （菜单项文字带助记符，如"粘贴(&P)"），取 y 最小的命中。
* **时间过滤基准必须取"打开菜单之前"的 tick**——菜单项在菜单打开瞬间渲染，
  用"当前时间-80ms"做下限会把刚渲染的菜单项全部滤掉。
* 打开菜单前先发 Esc 清掉可能残留的菜单，否则点击菜单栏变成"关闭"。
* 后台进程 SetForegroundWindow 会被前台锁拦截 → AttachThreadInput 强制前台，
  并校验 GetForegroundWindow，失败就放弃并提示。
* 查找宿主主窗口必须排除自己的浮窗（浮窗有标题且置顶，枚举序最靠前）
  并取面积最大者——否则菜单点击会落到浮窗坐标系（点在桌面上）。
* 粘贴菜单文字是"粘贴(&P)"，合并回层是"向下转写(&R)"——前缀匹配即可。

### 8.3 图层单独调整工作流（需求 3）

勾选「应用后合并回原层」后，完整闭环：

```
桥图层列表点行 → SAI2 选中该图层（点行屏幕坐标）→ Ctrl+A/C 抓取该层内容
→ 应用效果 → 回写剪贴板 → 编辑菜单粘贴（新层）→ 图层菜单「向下转写」
合并回原图层 → 调整只作用于目标层
```

### 8.4 PS 风格调整插件（com.sai2.adjust）

`调整` 分组：反相 / 去色 / 亮度对比度 / 色相饱和度 / 色阶（黑场/白场/Gamma），
全部支持选区与 Undo，桥面板参数带数值输入框（PS 风格滑杆+数值）。
