# SAI2 插件套件 · 使用说明

给 PaintTool SAI2 加一套图像处理功能：**模糊 / 滤镜 / 调整 / 液化**，处理完自动贴回原图层。

> 非官方工具，与 SAI2 官方无关。SAI2 本身没有插件接口（实测无导出表 / 无扩展机制），
> 所以走「伴随宿主 + 剪贴板桥」路线：插件跑在旁边的宿主里，用系统剪贴板与 SAI2 交换图像；
> 「连接注入」只**只读观察** SAI2 界面（IAT 钩子），用于读取图层名，不改 SAI2 代码。

---

## 1. 环境要求

- Windows 10 / 11 x64
- 免安装任何运行库（解压即用）
- SAI2 必须是 **64 位版**（32 位版会在「连接注入」时明确报错）
- 实测环境：SAI2 Preview 2023.04.05 x64 · Windows 11 23H2 + SAI2 20240522 x64

## 1.5 开始前：加杀毒软件白名单（重要）

本套件需要向 SAI2 注入一个**只读观察** DLL（用于读图层名），这类操作天然是
杀毒软件的重点关注对象。**首次使用前，先右键「以管理员身份运行」`添加白名单.bat`**，
把本目录加入 Windows Defender 排除项——否则 `sai2_agent.dll` 可能被静默拦截，
出现「注入完成但管道未就绪 (client lastErr=2)」。

- 360 / 火绒等第三方杀软：请在各自的「信任区 / 白名单」设置里手动添加本目录
- 不放心加白名单：可把 zip 上传 virustotal.com 自查；包内所有 exe/dll
  右键 → 属性 → 详细信息，都能看到完整的版本信息（产品名 / 版本 / 版权）
- 仍被误报：欢迎向杀软厂商提交误报申诉（Defender:
  microsoft.com/wdsi/filesubmission），申诉通过后全球白名单生效

## 2. 三步上手

1. 先打开 **SAI2**，并打开一幅画（面板靠剪贴板抓图，需要画布处于可复制状态）。
2. 双击 **`启动插件面板.bat`**（或直接运行 `sai2_bridge.exe`）→ 出现「SAI2 插件面板」。
3. 点面板上的 **「连接注入」**（SAI2 需正在运行）→ 图层列表出现、状态变「已连接」。

连上以后：SAI2 菜单栏右侧会出现一排功能按钮「模糊 | 滤镜 | 调整 | 液化」。

## 3. 两条用法路线

**路线 A（推荐）——在 SAI2 里点按钮**

点 SAI2 里那排按钮，或点面板上的同名按钮。两者都会自动：
在 SAI2 中选中当前图层 → 全选 + 复制 → 抓取像素 → 弹出该功能的**独立窗口**。

**路线 B（不用注入）——自己复制**

在 SAI2 里框选（或 Ctrl+A）→ **Ctrl+C**。面板监听到剪贴板就会自动抓图，
再点功能按钮开窗即可。

## 4. 四个功能窗口

| 窗口 | 包含 | 操作要点 |
| --- | --- | --- |
| **模糊** | 高斯 / 方框 / 动感 / 径向 | 顶部按钮切换算法，右侧滑杆 + 数值输入 |
| **滤镜** | 10 个：油画 / 水彩 / 粗糙蜡笔 / 素描 / 炭笔 / 粉笔 / 纹理化 / 颗粒 / 浮雕 / 查找边缘 | 左侧缩略图墙点选，右侧参数面板 |
| **调整** | 反相 / 去色 / 亮度对比度 / 色相饱和度 / 色阶 | 顶部按钮切换，参数即时预览 |
| **液化** | 向前变形 / 膨胀 / 收缩 / 顺时针旋转 / 逆时针旋转 / 平滑 / 重建 | 画布内**按住拖动涂抹**，逐笔累积 |

每个窗口底部都有：**应用 → 剪贴板** · **撤销** · **复位** · **关闭**。
每个窗口都有独立的预览会话（缩放 / 平移 / 液化置换场互不干扰），窗口位置会被记住。

## 5. 快捷键

| 按键 | 作用 |
| --- | --- |
| `Ctrl+Alt+G` | 抓取（当前 SAI2 图层 / 剪贴板） |
| `Ctrl+Alt+A` | 应用并回写剪贴板（并自动粘贴回 SAI2） |
| `Ctrl+Alt+Z` | 撤销上一次应用 |
| `Ctrl+Alt+R` | 复位到刚抓取到的原图 |
| 画布滚轮 | 以光标为锚缩放（2% ~ 3200%，过 100% 吸附） |
| 画布右键拖动 | 平移 |
| `[` / `]` | 液化笔刷大小 |
| `Shift+[` / `Shift+]` | 液化笔刷强度 |
| `Ctrl+Z`（液化窗口内） | 撤销上一笔涂抹 |
| `Esc` | 关闭当前功能窗口 |

## 6. 应用之后怎么回到 SAI2

点「**应用 → 剪贴板**」：把结果写入剪贴板（`CF_DIBV5` + `CF_DIB`，带 alpha）→
自动切回 SAI2 → 发送 `Ctrl+V` 粘贴回原图层。

- **不想自动粘贴**：取消勾选主面板的「应用后自动粘贴回 SAI2」，自己在 SAI2 里按 Ctrl+V。
- **只想改某一层**：勾选「应用后合并回原层（向下转写）」——调整只作用于目标图层。
- **想连续叠效果**：勾选「叠加处理（在当前结果上继续）」，下一次处理基于当前结果。
- **点图层行时在 SAI2 里选中**：勾选此项后，点面板图层列表的行会同步在 SAI2 里选中该层并抓图。

## 7. 常见问题

| 现象 | 处理 |
| --- | --- |
| 点了功能按钮没弹窗 | 抓取失败时面板会用「面板里现有的图像」开窗，注意看面板底部日志；确认 SAI2 已打开一幅画 |
| 图层列表是空的 | 点「连接注入」；面板只在内容变化时重绘，注入后点一下图层行即可出数据 |
| 粘贴回 SAI2 没有变化 | 确认粘贴目标是原图层且未被锁定 / 隐藏；或先点功能窗口里的「复位」 |
| 液化笔刷太卡 | 大画布上把笔刷调小；液化用全分辨率置换场，笔刷越大越吃 CPU |
| 想退出注入 | 命令行执行 `sai2_injector.exe eject`（重编译 `sai2_agent.dll` 前必须先 eject） |
| 要看日志 | 面板目录下 `logs\bridge.log`；SAI2 内的代理日志 `sai2_agent_<pid>.log` |
| 杀毒软件报毒 / 提示「注入完成但管道未就绪 (client lastErr=2)」 | 见 §1.5：右键管理员运行 `添加白名单.bat` 后重试；第三方杀软在信任区手动添加本目录 |
| 装插件后画画有延迟 | 1.14 已修复（图层缩略图改后台线程落盘 + 节流，不再拖慢绘画线程）。旧版可临时删除插件目录下 `thumbs\` 文件夹缓解 |
| 用完液化后整机一直卡，要重启 SAI2 才好 | 1.14 已修复（液化撤销快照按 384MB 内存预算限深；此前大画布 30 步快照可吃掉数 GB 内存把系统拖进交换） |
| 粘贴回图层后位置错位 | SAI2 的粘贴按**画布中心**对齐：通过面板/浮窗按钮抓的**整层**（图=画布尺寸）会精确重合；若是自己框选局部后 Ctrl+C 抓的，SAI2 会把粘贴内容放到画布中心，需用移动工具摆位（SAI2 剪贴板不携带位置信息，任何工具都无法规避） |
| 勾了「应用后合并回原图层」但还在新图层上 | 1.15 已修复（此前合并步骤从未被执行）；现在通过 SAI2 原生「向下转写」（F 键）合并，不再依赖菜单定位 |
| SAI2 里的浮动按钮条点了没反应 / 面板关了按钮条还在 | 1.15 已改进：抓取失败会自动重试一次；面板退出或挂死后浮动按钮条会在 4 秒内自动隐藏，重新连接后恢复显示 |
| 功能窗口弹出了但藏在 SAI2 后面 / 只闪任务栏 | 1.16 已修复：功能窗口用三级置前策略（借用前台线程权限 → Alt 解锁 → 闪任务栏兜底），从 SAI2 里再次点击浮窗按钮也会把已打开的窗口可靠地拉到最前 |
| 粘贴回 SAI2 后错位很多 | 1.18 已修复：实测发现 SAI2 的复制（包括 Ctrl+A 全选后复制）只会拷出图层的**上色部分包围盒**，透明区域被裁掉，所以剪贴板里的图永远≠画布尺寸，按画布中心粘贴必然错位。1.18 默认改用 **Ctrl+Shift+V 原位粘贴**——贴进当前图层、保持复制时的位置，天然精确对齐（面板选项「原位粘贴」可关）。关闭原位粘贴时回退为居中粘贴 + 向下转写，那种方式只适合内容恰好铺满画布的图层 |

## 8. 自检（不碰 SAI2，随时可跑）

```bat
sai2_bridge.exe --selftest --out selftest-out    :: 端到端自检，实测 PASS=58 FAIL=0（退出码 = 失败项数）
sai2_bridge.exe --uitest                         :: 界面冒烟：打开全部 4 个功能窗口后自动退出
sai2_injector.exe selftest                       :: 注入链路自检 8/8（用假 SAI2，不碰真 SAI2）
```

## 9. 卸载

直接删掉整个文件夹即可。残留只有两处，都可手动清：
`plugins\registry.json`（插件启用状态）与注册表 `HKCU\Software\SAI2Bridge`（主题、窗口位置记忆）。
