# SAI2 插件套件

SAI2 没有官方插件接口，本套件以「伴随宿主 + 注入代理」的方式为 SAI2 补上实用的图像处理功能：
**液化、模糊、滤镜、调整**。插件跑在独立面板里，通过剪贴板与 SAI2 交换图像，处理完一键贴回原图层。

- **一功能一窗口**：点面板按钮即抓取 SAI2 当前图层并打开对应功能窗口，窗口可自由缩放、位置记忆
- **液化**：向前变形 / 膨胀 / 收缩 / 旋转 / 平滑 / 重建，笔刷大小可调，笔级撤销（Ctrl+Z）
- **滤镜**：10 个滤镜缩略图墙，参数滑杆 + 数值输入（PS 风格）
- **模糊 / 调整**：4 种模糊；反相 / 去色 / 亮度对比度 / 色相饱和度 / 色阶
- **注入代理**：只读方式识别 SAI2 图层面板，面板里点某一行即在 SAI2 选中该层
- **回贴原层**：可选「应用后合并回原层」，处理结果自动合并到目标图层

## 使用

到 [Releases](../../releases) 下载最新的 `sai2-plugin-suite-x.xx.zip`，解压后：

1. **先右键「以管理员身份运行」`添加白名单.bat`**——把本目录加入 Windows Defender 排除项，
   否则杀软可能静默拦截 `sai2_agent.dll`（360/火绒等第三方杀软请在信任区手动添加本目录）；
2. 启动 SAI2 并打开一幅画；
3. 双击 `启动插件面板.bat`，点「连接注入」，图层列表出现即就绪；
4. 点面板上的「液化 / 模糊 / 滤镜 / 调整」→ 自动抓取当前图层并打开功能窗口；
5. 处理完点「应用 → 剪贴板」，自动切回 SAI2 粘贴回原图层。

**环境要求**：Windows 10/11 x64，无需安装任何运行库；SAI2 需为 64 位版。
**全局快捷键**：`Ctrl+Alt+G` 抓取 / `Ctrl+Alt+A` 应用 / `Ctrl+Alt+Z` 撤销 / `Ctrl+Alt+R` 复位。

详细用法（快捷键表 / 常见问题 / 注入原理）见 [docs/使用说明.md](docs/使用说明.md)。
